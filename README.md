# 教育用コンパイラ Proto言語処理系

[English](README.en.md)

Proto言語とその言語処理系は、拡張を前提として設計されたコンパイラ学習用の教材です。
プログラミング演習を通じて、字句解析器、構文解析器、抽象構文木の変換による最適化、コード生成、仮想マシンを拡張することで、それらの仕組みを学べます。

- [インストール・実行方法](docs/how_to_use_compiler.md)
- [Proto言語仕様](docs/protolang_spec.md)
- [Proto仮想マシン仕様](docs/vm_spec.md)
- [サンプルプログラム](examples/README.md)
- [演習](exercises/README.md)

このドキュメントで示すコマンドは、特に断りがない限り、リポジトリのルートディレクトリをカレントディレクトリとして実行します。
