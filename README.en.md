# Educational Compiler: Proto Language Processing System

[Japanese](README.md)

Proto and its language processing system are teaching materials for learning about compilers and are designed to be extended.
Through programming exercises, you can learn how lexical analyzers, parsers, AST-based optimization, code generation, and virtual machines work by extending these components.
