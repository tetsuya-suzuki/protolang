# Exercise 2-2: Extending the Parser

[Japanese](2_parser.md)

## Task

Implement the following syntax extensions defined in the [Proto Language Extension Specification](0_extension_spec.en.md) in the parser.

- Remainder operation
- do-while statement
- repeat-until statement
- Omission of `else`
- Logical operators

Follow the production-rule changes in the specification above.

## Running the Tests

```console
$ ./test 2
```

To display detailed information for failed tests, specify the `--details` option.

```console
$ ./test 2 --details
```
