# Exercise 2-1: Extending the Lexer

[Japanese](1_lexer.md)

## Task

Implement the lexical-analysis features among the extensions defined in the [Proto Language Extension Specification](0_extension_spec.en.md).

Implement the following features:

- Remainder operation
- do-while statement
- repeat-until statement
- Logical operators

Refer to the specification above for the lexical elements to be added for each feature.
