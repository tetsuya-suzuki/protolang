# 演習1-1 アセンブリ言語プログラミング

[English](1_assembly.en.md)

この文書の目的は、アセンブリ言語のプログラムは高水準言語のプログラムと比べて抽象度の低い命令で構成されていることを確認することである。

[Proto仮想マシンの仕様書](../../docs/vm_spec.md)も参照しながら、下記の説明を読んだ上で、この文書の最後にある課題に取り組む。

## 大域変数

大域変数を利用する場合、`.globals`ディレクティブで使用する大域変数の個数を指定する。
次の例では大域変数を3つ使用することを宣言する。

```text
.globals 3
```

大域変数は番号(0, 1, 2, ...)で指定する。

大域変数への代入には`STOREG`命令を使う。
次の例では、スタックに積まれた2を0番の大域変数に代入する。

```text
IPUSH 2
STOREG 0
```

大域変数の値を読むには`LOADG`命令を使う。
次の例では、0番の大域変数の値をスタックにプッシュする。

```text
LOADG 0
```

次のプログラム`globals.pta`を実行してみよう。

```text
.globals 1
IPUSH 2
STOREG 0
LOADG 0
HALT
```

実行方法と結果は次のようになる。`--trace-vm`オプションによって、スタックと大域変数の変化をステップごとに確認できる。

```console

--------------------------------------------------

--------------------------------------------------
NEXT : LOADG 0
pc=2  sp=0  fp=0
stack  : []

```

## 文字出力

Proto仮想マシンには指定したASCIIコードの文字を出力する命令CPRINTがある。
これは通常のOSでのシステムコールに相当する。

ASCIIコードの例を紹介する。

- 文字' '（空白）
  - 10進数でのASCIIコード32
- 文字'*'
  - 10進数でのASCIIコード42
- 文字'-'
  - 10進数でのASCIIコード45
- 文字'0'
  - 10進数でのASCIIコード48
- 文字'1'
  - 10進数でのASCIIコード49

次の例(`print_star.pta`)は'*'を1つ出力する。

```text
.globals 0
IPUSH 42
CPRINT
HALT
```

上記のプログラムを実行すると次のようになる。改行はされないので、'*'の横にシェルのプロンプトが表示されるだろう。

```console
$ ./ptlc --run-asm exercises/1/print_star.pta
*
```

## 四則演算

整数の四則演算には`IADD`, `ISUB`, `IMUL`, `IDIV`命令（それぞれ +, -, *, /に対応）がある。

次のプログラム片は、0番の大域変数の値に1を足した値をスタックにプッシュする。

```text
LOADG 0
IPUSH 1
IADD
```

## 比較演算

比較演算には`IEQ`, `INE`, `ILT`, `ILE`, `IGT`, `IGE`命令（それぞれ =, !=, <, <=, >, >=に対応）がある。

次のプログラム片は、条件式 (0番の大域変数の値) > 1 が真ならば1(真)、そうでなければ0(偽)をスタックにプッシュする。

```text
LOADG 0
IPUSH 1
IGT
```

## 条件分岐

条件分岐には`JPZ`命令がある。スタックからポップした値が0ならば、指定された番地にジャンプする命令である。0は偽を表す値である。

次のプログラム片は、条件式 (0番の大域変数の値) > 1 が偽ならば、JPZ命令によって`ELSE`へジャンプする。ジャンプ先ではスタックに0をプッシュする。
もしその条件式が真の場合は1をプッシュしてから`JMP`命令によって`ENDIF`へジャンプする。

```text
      LOADG 0
      IPUSH 1
      IGT
      JPZ ELSE
      IPUSH 1
      JMP ENDIF
ELSE:
      IPUSH 0
ENDIF:
```

## 演習問題

0番目の大域変数で指定された個数だけ`-`を表示するアセンブリ言語プログラム`print_line.pta`を書きなさい。

ヒント:下記の`STOREG`と`HALT`の間を埋めればよい。

```text
.globals 1
IPUSH 10
STOREG 0

HALT
```
